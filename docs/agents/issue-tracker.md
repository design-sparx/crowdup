# Issue tracker

## Tracker

GitHub Issues for `design-sparx/crowdup`, accessed with the `gh` CLI. `to-tickets`, `to-spec`, and related skills create and update issues here.

## PRs as a request surface

Off. Pull requests are not imported into the triage queue. Set `prsAsRequestSurface: true` below only if you want external PRs treated as triage requests.
