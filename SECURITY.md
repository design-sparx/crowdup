# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public GitHub issue, pull request or discussion for a security problem.

Use GitHub's private vulnerability reporting:

1. Go to https://github.com/design-sparx/crowdup/security/advisories/new
2. Describe the issue, the steps to reproduce it, and the affected version or commit.

If you cannot use that form, contact the maintainer through their GitHub profile at https://github.com/kelvink96 and ask for a private channel.

We aim to acknowledge a report within a few days and will keep you updated as we investigate. Please give us a reasonable chance to fix the issue before disclosing it publicly.

## Supported versions

Only the latest release on `main` receives security fixes.
